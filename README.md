## 収率計算ノート (`yield-calculator/`)

有機合成実験の仕込み量・当量・律速試薬・理論収量・収率を計算する単一 HTML アプリ。
`yield-calculator/index.html` をブラウザで開くだけで使えます（ビルド不要）。

- 分子式から分子量を自動計算（括弧・水和物・Me/Et/Ph/Boc などの略号に対応）
- 質量 / 体積＋密度 / 溶液＋濃度 / 当量指定（必要量を逆算）の 4 通りの入力
- 化学量論係数による律速試薬の判定（例: ジピロリルベンゼン 2 + アルデヒド 2 → ジベンゾポルフィリン(2.1.2.1) 1）と純度補正込みの収率
- 反応テンプレート: 鈴木–宮浦、o-ジピロリルベンゼン前駆体、ジベンゾポルフィリン(2.1.2.1)、Lindsey 法、ジピロメタン
- 比の計算: 比例式 a:b = c:x と、複数の値（質量→モル換算可）の比・整数比
- 名称から自動入力: 登録試薬 → 組込み試薬 → PubChem → Claude（Artifact 版のみ）の順に検索
- 試薬ライブラリ: よく使う試薬を登録・編集し、JSON でバックアップ／移行
- 実験ノートに貼れるテキストをコピー
