# 有機合成 実験ノートアプリ

仕様は リポジトリ直下の `SPEC.md` を参照。

## 使い方

`index.html` をPCのブラウザ（Chrome / Edge 推奨）で開くだけで動きます。ビルドやサーバーは不要です。
フォルダごと（`js/`・`css/`・`vendor/` を含めて）コピーして使ってください。

1. **試薬・化合物ライブラリ** でよく使う試薬を登録（分子量・密度・濃度・純度）。★でお気に入り
2. **ノート一覧 → ＋新しいノート**
3. 反応式：ChemDraw で CDXML 保存したファイルをドロップ（または MOL / SMILES を貼り付け）
4. 試薬表：「＋試薬を追加」でライブラリから選ぶ → 基準試薬の質量と、他の試薬の当量を入れる
5. 手順：操作ボタンを押して入力 → 日本語文・英語文が自動でできる（「コピー」で太字付きのまま Word に貼れる）
6. 「保存」（Ctrl+S）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の枠（ヘッダー・ナビ）と読み込み順 |
| `js/util.js` | 共通（DOM・検索の正規化・数値の丸め・ダイアログ） |
| `js/repository.js` | **リポジトリ層**。データの読み書きはすべてここを通す。保存先を変えるときはこのファイルのアダプタを差し替える |
| `js/calc.js` | 試薬表の計算（双方向計算・反応濃度・収率） |
| `js/chem.js` | 構造式の読み込み（CDXML / MOL / RXN / SMILES）・分子式と分子量・SVG 表示 |
| `js/operations.js` | 操作ボタンの定義と日英テンプレート、操作の入力フォーム |
| `js/library.js` | 試薬・化合物ライブラリ画面、登録フォーム、選択ダイアログ |
| `js/ketcher.js` | Ketcher（構造式エディタ）の呼び出し |
| `js/editor.js` | ノート編集画面 |
| `js/app.js` | 画面の切り替え、ノート一覧（検索） |
| `css/style.css` | 見た目（配色は試薬台帳アプリに合わせている） |
| `vendor/ketcher/` | Ketcher 本体（Apache 2.0）。作り直し方はフォルダ内の README |

## 保存先

今はブラウザ内（IndexedDB）に保存します。ブラウザやPCごとに別々のデータになり、
ブラウザのサイトデータを消すとノートも消えます（保存先の決定は SPEC 9章のステップ7）。

## 構造式についての注意

- 取り込んだ CDXML は元ファイルのまま保存し、「元の CDXML をダウンロード」で ChemDraw でそのまま開けます
- ノート上の図は確認用の簡易表示です（フォント・線の太さなどは ChemDraw と同じにはなりません）
- Ketcher で修正した構造は、元ファイルとは別に「修正版」として保存します（RXN / MOL と CDXML）
- 分子量は構造から計算します。略号（OMe, Ph など）は CDXML 内の展開情報があれば数えます
- CDX（バイナリ）と MOL V3000 は未対応です（ChemDraw で CDXML / MOL V2000 として保存してください）
