# 有機合成 実験ノートアプリ

仕様は リポジトリ直下の `SPEC.md` を参照。

## 使い方

`index.html` をブラウザ（PC）で開くだけで動きます。ビルドやサーバーは不要です。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の枠（ヘッダー・ナビ） |
| `js/repository.js` | **リポジトリ層**。データの読み書きはすべてここを通す。保存先を変えるときはこのファイルのアダプタを差し替える |
| `js/app.js` | 3つの画面（ノート一覧・ノート編集・試薬・化合物ライブラリ） |
| `css/style.css` | 見た目（配色は試薬台帳アプリに合わせている） |

## 保存先

今はブラウザ内（IndexedDB）に保存します。ブラウザやPCごとに別々のデータになり、
ブラウザのサイトデータを消すとノートも消えます（保存先の決定は SPEC 9章のステップ7）。
